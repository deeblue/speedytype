# SpeedyType Documentation Archive

> This archive is historical evidence, not current instructions. Dates, paths,
> gates, and conclusions reflect the time each file was written. Use
> [`docs/current/`](../current/) for current product and release state.

Archived files remain unchanged so Git history, decisions, and experiment
evidence remain auditable. When an archived statement conflicts with a current
document, the current document is authoritative.

## Categories

- [`plans/`](plans/) contains completed implementation plans and older project
  plans.
- [`specs/`](specs/) contains approved and completed design specifications.
- [`reports/`](reports/) contains phase, POC, voice-quality, investigation, and
  dated limitations reports.
- [`experiments/long-recording/`](experiments/long-recording/) contains the
  long-recording investigation and its successive evaluation plans.
- [`experiments/macos/`](experiments/macos/) contains preserved real-macOS setup
  and crash logs.

For active product behavior, release gates, and next actions, return to the
[documentation hub](../README.md).
